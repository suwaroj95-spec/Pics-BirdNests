เราพร้อมสร้างโมเดลหรือยัง?

คำตอบตอนนี้คือ: ข้อมูล crop ใช้ทำการทดลองเบื้องต้นได้ แต่ผลยังไม่นิ่งพอสำหรับตัดสินใจใช้งานจริง สิ่งที่ควรทำก่อนคือดูภาพตัวอย่างที่โมเดลพลาด ปรับมาตรฐานการถ่ายภาพ และเพิ่มภาพต้นฉบับอิสระ

ข้อมูลไม่มีร่องรอย marker รั่วเข้าโมเดล โมเดลเบื้องต้นยังแกว่งตามภาพต้นฉบับ ยังไม่ควรทำระบบใช้งานจริง
สรุปสำหรับผู้บริหาร

งานล่าสุดพาเราไปถึงขั้นรู้แล้วว่า “ปัญหาอยู่ตรงไหน”

เราไม่ได้หยุดแค่สร้าง crop หรือ train โมเดลทดลอง แต่ตรวจต่อว่าโมเดลพลาดกับภาพต้นฉบับแบบไหน ผลที่ได้ชี้ว่าโมเดลมีสัญญาณแยก dirty/clean ได้จริงบางส่วน แต่ยังอ่อนไหวกับภาพแต่ละชุดมากเกินไป

ตัวเลขสำคัญ แปลเป็นภาษางานจริง

ตารางนี้ตั้งใจเลี่ยงศัพท์เทคนิคเกินจำเป็น และชี้ว่าตัวเลขแต่ละชุดบอกอะไรกับเรา

สิ่งที่วัด ค่าที่ได้ ความหมายแบบไม่เทคนิค
ความสะอาดของข้อมูล crop 3,469 crop ใช้ได้ครบ, ไม่มี crop ที่ตามรอยไม่ได้ เรารู้ว่าภาพย่อยแต่ละภาพมาจากไหน จึงตรวจย้อนหลังได้
ความเสี่ยงจาก marker สีฟ้า marker-like = 0 โมเดลไม่น่าจะใช้สี marker เป็นทางลัดในการทายผล
โมเดลเบื้องต้นบน test set accuracy 88.66%, precision 87.68%, recall 90.69%, F1 89.16% ดูดีบน test set เดิม แต่ยังสรุปไม่ได้ว่าพร้อมใช้งาน เพราะจำนวนภาพต้นฉบับมีน้อย
ความนิ่งเมื่อเปลี่ยนภาพต้นฉบับ F1 ต่อภาพต้นฉบับต่ำสุด 44.87%, สูงสุด 92.81% โมเดลทำงานไม่สม่ำเสมอ บางภาพง่าย บางภาพยากมาก
ภาพที่โมเดลพลาด clean ถูกทายว่า dirty 611 crop, dirty ถูกทายว่า clean 256 crop มีทั้งการเตือนเกินและการพลาดของสกปรก จึงต้องดูสาเหตุจากภาพจริง
Problem Signals

Output ที่ชี้ว่าปัญหาคืออะไร

1. ผลไม่เหมือนกันเมื่อเปลี่ยนภาพต้นฉบับ

แปลว่าโมเดลยังอ่อนไหวกับสภาพภาพ เช่น แสง พื้นหลัง มุม หรือ texture ของรังนกแต่ละภาพ

  • source-wise decision: BASELINE_UNSTABLE
  • threshold ที่เหมาะในแต่ละ fold ต่างกันมาก: 0.15 ถึง 0.85

2. มีทั้งการเตือนเกินและการพลาดของสกปรก

ถ้าเป็นปัญหาเดียว ตัวเลขมักเอียงไปทางเดียว แต่ตอนนี้บาง source เน้น over-flagging บาง source เน้น under-detection

  • clean ถูกทายว่า dirty: 611 crop
  • dirty ถูกทายว่า clean: 256 crop

3. ต้องตรวจภาพจริง ไม่ใช่ดูตัวเลขอย่างเดียว

เราได้สร้าง contact sheets เพื่อให้คนดูว่าข้อผิดพลาดเกิดจากคราบเล็ก ภาพมืด พื้นหลังคล้ายสกปรก หรือกติกา crop ไม่ชัด

  • contact sheets: 38 ไฟล์
  • ตัวอย่าง error ที่คัดมา: 215 crop

Cause Hypotheses

สาเหตุที่น่าจะเป็น

ยังไม่ฟันธงจนกว่าจะเปิด contact sheets แต่หลักฐานชี้ไปที่สาเหตุผสม ไม่ใช่แค่โมเดลยังเล็กเกินไป

แสงและพื้นหลังไม่คงที่

บางภาพอาจมีเงา พื้นหลัง หรือ texture ที่ทำให้ clean ดูเหมือน dirty

คราบบางจุดเล็กหรือไม่ชัด

บาง dirty crop อาจมีคราบเล็กมาก หรืออยู่ขอบภาพ ทำให้โมเดลมองเป็น clean

กติกา clean/dirty อาจยังมีขอบเขตกำกวม

บางกรณีอาจต้องให้คนตกลงนิยามว่า crop แบบใดควรนับเป็น clean หรือ dirty

threshold ใช้ข้าม source ได้ไม่ดี

ค่าที่เหมาะกับภาพหนึ่งอาจไม่เหมาะกับอีกภาพ แปลว่าต้องเพิ่มความหลากหลายของภาพก่อน

Strategic Decision

ยังไม่ควรทำ Object Detection หรือโมเดลซับซ้อนต่อทันที

เหตุผลคือเรายังไม่รู้แน่ชัดว่า error มาจากการถ่ายภาพ กติกา crop/label หรือความต่างระหว่างภาพต้นฉบับ ถ้าเพิ่มโมเดลซับซ้อนตอนนี้ อาจทำให้แก้ผิดจุดและวิเคราะห์ยากขึ้น

สิ่งที่ควรทำก่อน

  • ตรวจ contact sheets กับคนที่รู้งานจริง
  • กำหนดมาตรฐานแสง ระยะ มุม และพื้นหลัง
  • เพิ่มภาพต้นฉบับอิสระ ไม่ใช่เพิ่ม crop จากภาพเดิม
  • ทบทวนกติกา crop เฉพาะเคสกำกวม

หลังทำเสร็จแล้ว

  • รัน baseline รอบใหม่ด้วย workflow เดิม
  • เทียบกับผลรอบนี้แบบตัวต่อตัว
  • ดูว่า source-wise variation ลดลงหรือไม่
  • ค่อยออกแบบ model experiment ถัดไป
