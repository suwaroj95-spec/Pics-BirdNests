Developer Quick Start

คู่มือเริ่มต้นสำหรับทีมโปรแกรมเมอร์

คู่มือแบบทำตามทีละขั้น ตั้งแต่ดาวน์โหลดไฟล์ ติดตั้งระบบ รันโมเดล และเปิดดูผลลัพธ์ครั้งแรก

สถานะEngineering Prototype
ข้อจำกัดยังไม่ใช่ Production

เริ่มต้นใช้งานทีละขั้น

ลำดับนี้คือเส้นทางจากเครื่องเปล่าไปจนถึงผล Inference แรก ให้ทำตามจากซ้ายไปขวา หรือจากบนลงล่างบนมือถือ

  1. เตรียมเครื่อง
  2. ดาวน์โหลด Checkpoint
  3. ตรวจ SHA256
  4. เตรียมภาพ
  5. รัน CPU หรือ CUDA
  6. เปิด Preview
  7. เปิด predictions.json
  8. แก้ปัญหาเบื้องต้น
  9. สาธิตให้หัวหน้าดู

เตรียมเครื่อง

  • Windows 10 หรือ Windows 11
  • Python 3.12.5
  • Git
  • พื้นที่ว่างสำหรับ Repository และ Checkpoint
  • final_checkpoint.pt
  • ภาพรังนกสำหรับทดลองอย่างน้อย 1 ภาพ
  • NVIDIA GPU เป็นทางเลือก ไม่จำเป็นสำหรับ CPU mode

คำสั่งตามลำดับ

  1. Clone หรืออัปเดต Repository

    ถ้ายังไม่มีโครงการในเครื่อง ให้ Clone ลงในโฟลเดอร์ตัวอย่างด้านล่าง

    ตัวอย่างนี้ใช้โฟลเดอร์ C:\Projects สำหรับเก็บโครงการ ผู้ใช้งานสามารถเปลี่ยนตำแหน่งได้ตามโครงสร้างและสิทธิ์ของเครื่องปลายทาง

    New-Item -ItemType Directory -Force C:\Projects | Out-Null
Set-Location C:\Projects
git clone https://github.com/suwaroj95-spec/Pics-BirdNests.git
Set-Location C:\Projects\Pics-BirdNests

    ถ้ามี Repository อยู่แล้ว ให้ใช้คำสั่งนี้เพื่ออัปเดตแบบ fast-forward เท่านั้น

    Set-Location C:\Projects\Pics-BirdNests
git pull --ff-only origin main

    ผลที่ควรได้: โฟลเดอร์ C:\Projects\Pics-BirdNests พร้อมไฟล์เอกสารและเครื่องมือของโครงการ

  2. สร้าง Python virtual environment

    ใช้ .venv-demo เพื่อไม่รบกวน environment อื่นของโครงการ

    python -m venv .venv-demo
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv-demo\Scripts\Activate.ps1
python -m pip install --upgrade pip

    ผลที่ควรได้: PowerShell ใช้ Python จาก .venv-demo และ pip เป็นเวอร์ชันล่าสุดใน environment นี้

  3. ติดตั้ง PyTorch และ Runtime packages

    ติดตั้ง Runtime packages ของโครงการ และเลือก PyTorch/Torchvision ให้ตรงกับ CPU หรือ CUDA ที่ต้องการใช้งาน

    python -m pip install -r .\InstallKit\requirements-model-common.txt

    PyTorch/Torchvision ต้องตรงกับแพลตฟอร์ม CPU หรือ CUDA ที่จะใช้จริง สำหรับ CUDA ให้ใช้คำสั่งจาก official PyTorch selector เท่านั้น อย่าเดา CUDA wheel URL เอง

    ผลที่ควรได้: Python import torch, torchvision, Pillow, numpy, และ pandas ได้

  4. ดาวน์โหลด Checkpoint

    สร้างโฟลเดอร์สำหรับ asset และดาวน์โหลด final_checkpoint.pt จาก Release ที่อนุมัติแล้ว

    New-Item -ItemType Directory -Force .\model_assets | Out-Null
New-Item -ItemType Directory -Force .\demo_input | Out-Null
New-Item -ItemType Directory -Force .\demo_output | Out-Null
    Invoke-WebRequest `
  -Uri "https://github.com/suwaroj95-spec/Pics-BirdNests/releases/download/v0.1.0-prototype/final_checkpoint.pt" `
  -OutFile ".\model_assets\final_checkpoint.pt"

    ผลที่ควรได้: มีไฟล์ .\model_assets\final_checkpoint.pt ในเครื่อง

  5. ตรวจ SHA256

    ตรวจ hash ก่อนใช้งานทุกครั้ง เพื่อยืนยันว่า Checkpoint ตรงกับ Release asset ที่อนุมัติแล้ว

    (Get-FileHash `
  .\model_assets\final_checkpoint.pt `
  -Algorithm SHA256).Hash

    ค่าที่ควรได้: 660b59465e1514f39eae79c4a53d2cc4181c0d829bd1365be853c6260b0def5c

    ค่าที่แสดงต้องตรงทุกตัวอักษร หากไม่ตรงห้ามใช้ไฟล์นั้น

  6. เตรียมภาพทดลอง

    คัดลอก JPG หรือ PNG อย่างน้อย 1 ภาพลงใน demo_input\ สำหรับการสาธิตที่อ่านง่าย ควรใช้ 1-3 ภาพเท่านั้น

    Pics-BirdNests\ ├─ model_assets\ │ └─ final_checkpoint.pt ├─ demo_input\ │ └─ sample.jpg └─ demo_output\

    อย่าใช้ Marker images เป็น input ปกติของ Inference และอย่าอ้างว่าภาพเป็นภาพที่โมเดลไม่เคยเห็น เว้นแต่ตรวจสอบ dataset lineage แล้ว

    ผลที่ควรได้: demo_input\ มีภาพรังนกที่ต้องการทดลอง

  7. รัน Inference

    เริ่มด้วย CPU ก่อนหากยังไม่แน่ใจว่า CUDA พร้อมหรือไม่

    python -c "import torch, torchvision; print('torch:', torch.__version__); print('torchvision:', torchvision.__version__); print('CUDA available:', torch.cuda.is_available()); print('Device:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
    python .\tools\run_prototype_inference.py `
  --input .\demo_input `
  --output .\demo_output `
  --checkpoint .\model_assets\final_checkpoint.pt `
  --config .\handoff\prototype_v1\prototype_runtime_config.json `
  --threshold 0.125 `
  --device cpu `
  --save-json predictions.json `
  --save-preview previews

    ผลที่ควรได้: คำสั่งจบด้วยสถานะ PROTOTYPE_INFERENCE_COMPLETE และสร้างไฟล์ผลลัพธ์ใน demo_output\

  8. เปิดดูผลลัพธ์

    เปิดโฟลเดอร์ผลลัพธ์ ภาพ Preview และไฟล์ JSON เพื่อตรวจทบทวน

    Invoke-Item .\demo_output
Invoke-Item .\demo_output\previews
notepad .\demo_output\predictions.json

    ผลที่ควรได้: เห็น predictions.json และภาพ Preview ที่แสดงกรอบเสนอโดยโมเดล

เริ่มแบบไหนดี

CPU

  • ใช้ได้กับเครื่องทั่วไป
  • ติดตั้งง่ายกว่า
  • เหมาะสำหรับการทดสอบครั้งแรก
  • ทำงานช้ากว่า GPU

CUDA

  • ใช้กับ NVIDIA GPU
  • ต้องติดตั้ง PyTorch build ให้ตรงกับ Driver/CUDA
  • เหมาะกับการสาธิตบนเครื่องโมเดล
  • อย่าเดา CUDA package URL ให้ใช้ official PyTorch selector

คำแนะนำ: เริ่มด้วย CPU ก่อน หากยังไม่แน่ใจว่า CUDA พร้อมหรือไม่

สำหรับเครื่องที่จะใช้ CUDA ให้รันคำสั่งตรวจสอบนี้ก่อน และอย่าอ้างว่า CUDA ใช้ได้ถ้ายังไม่ได้ตรวจ

python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU only')"

เมื่อคำสั่งตรวจสอบพร้อมแล้ว สามารถใช้ Inference แบบ CUDA โดยเปลี่ยนเฉพาะ --device cuda

python .\tools\run_prototype_inference.py `
  --input .\demo_input `
  --output .\demo_output `
  --checkpoint .\model_assets\final_checkpoint.pt `
  --config .\handoff\prototype_v1\prototype_runtime_config.json `
  --threshold 0.125 `
  --device cuda `
  --save-json predictions.json `
  --save-preview previews

ผลลัพธ์ที่ควรได้

demo_output\ ├─ predictions.json └─ previews\ └─ sample_prototype_preview.jpg

predictions.json มีข้อมูล

  • source filename
  • source dimensions
  • threshold
  • score
  • bounding-box coordinates
  • center coordinates
  • runtime warnings

Preview มีข้อมูล

  • original image
  • model-proposed boxes
  • confidence score
  • Prototype disclaimer

กรอบที่แสดงเป็นข้อเสนอจากโมเดลสำหรับการตรวจทบทวน ไม่ใช่คำยืนยันจากผู้เชี่ยวชาญว่าจุดนั้นสกปรกจริง

Threshold คืออะไร

Threshold คือคะแนนขั้นต่ำที่ระบบใช้ตัดสินว่าจะเก็บผลการทำนายนั้นไว้แสดงหรือไม่

  • score 0.20 with threshold 0.125 → แสดง
  • score 0.13 with threshold 0.125 → แสดง
  • score 0.08 with threshold 0.125 → ไม่แสดง

0.125 ไม่ได้หมายความว่าโมเดลมีความแม่นยำ 12.5%

Threshold 0.125

  • ค่าหลักของ Prototype
  • เน้น Recall
  • แสดงจุดมากกว่า
  • ภาระตรวจทบทวนมากกว่า

Threshold 0.175

  • ใช้เพื่อเปรียบเทียบ
  • แสดงจุดน้อยกว่า
  • ภาระตรวจลดลง
  • Recall ที่วัดได้ต่ำกว่า

  1. เปิดภาพต้นฉบับ 1 ภาพ
  2. แสดงคำสั่ง CPU หรือ CUDA ที่เตรียมไว้
  3. รัน Inference
  4. เปิด Preview
  5. เปิด predictions.json
  6. อธิบาย Threshold 0.125
  7. ย้ำว่าเป็น Engineering Prototype

สคริปต์พูด: ระบบรับภาพรังนก แบ่งภาพตามค่าที่กำหนดไว้ใน Runtime Config ตรวจหาตำแหน่งที่มีลักษณะคล้ายจุดสกปรก และส่งผลออกมาเป็นภาพ Preview กับข้อมูลพิกัดใน JSON ผลลัพธ์ยังต้องได้รับการตรวจทบทวนจากผู้เชี่ยวชาญก่อนนำไปใช้ตัดสินจริง

ข้อจำกัดที่ต้องเข้าใจก่อนใช้งาน

  • เป็น Engineering Prototype
  • ไม่ใช่ระบบ Production
  • Architecture: FasterRCNN_MobileNetV3-Large-FPN, Classes: 2, Backbone: frozen
  • Approved Prototype dataset scope คือ 240 raw/marker pairs และไม่ควรอธิบายว่าเป็น training images ทั้งหมด
  • Validation scope ยังมีจำกัด: 36 source images และ 432 model-input tiles
  • Primary Recall ที่รายงานไว้คือ 70.99%
  • ยังไม่ได้รับรอง Production throughput
  • CUDA performance ต้องทดสอบบนเครื่องปลายทาง
  • ผู้เชี่ยวชาญยังต้องตรวจผล
  • MODEL_ONLY_MARKER_ABSENT ไม่ใช่ False Positive โดยอัตโนมัติ และไม่ได้แปลว่าเป็น expert-confirmed dirty spot หรือ Marker ผิดเสมอไป
  • ห้ามเผยแพร่ Raw/Marker master datasets โดยไม่ได้รับอนุญาต
