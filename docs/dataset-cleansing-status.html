สถานะการเตรียมข้อมูล

สรุปความคืบหน้าการทำความสะอาดชุดข้อมูล

สถานะการตรวจสอบและรับรองคุณภาพข้อมูลภาพรังนก ก่อนนำไปสร้างภาพย่อยและพัฒนาโมเดล

สถานะโดยรวม

ชุดข้อมูลที่ 1-3 ทำความสะอาด ตรวจสอบคุณภาพ และพร้อมสำหรับสร้างภาพย่อย (Crop A) แล้ว การฝึกโมเดลรอบหลักควรเริ่มเมื่อมีข้อมูลที่ผ่านการรับรองอย่างน้อย 300 คู่ภาพ

อัปเดตล่าสุด: -

ภาพรวมสำหรับผู้บริหาร

ตัวเลขสำคัญของข้อมูลที่ผ่านการรับรองและเป้าหมายระยะถัดไป

0% ของเป้าหมาย 300 คู่

ความคืบหน้าสู่เกณฑ์เริ่มฝึกโมเดลหลัก

ขณะนี้ชุดข้อมูลทั้ง 3 ชุดพร้อมสำหรับสร้างภาพย่อยแล้ว อย่างไรก็ตาม การฝึกโมเดลรอบหลักจะเริ่มเมื่อมีข้อมูลที่ผ่านการรับรองอย่างน้อย 300 คู่ภาพ

ผลการทำความสะอาดข้อมูลแยกตามชุด

ทุกชุดใช้โครงสร้างการรายงานเดียวกัน เพื่อให้เปรียบเทียบสถานะได้ชัดเจน

สถานะความพร้อมปัจจุบัน

ขั้นตอนถัดไป: รับและตรวจสอบข้อมูลชุดถัดไป เพื่อให้มีข้อมูลผ่านการรับรองครบอย่างน้อย 300 คู่ภาพก่อนเริ่มการฝึกโมเดลรอบหลัก

หมายเหตุการตรวจสอบข้อมูล

  • ไฟล์ที่ไม่นำมาใช้ยังถูกเก็บไว้ พร้อมบันทึกเหตุผล เพื่อให้ตรวจสอบย้อนหลังได้
  • ข้อมูลจะนับเป็นคู่ภาพที่ผ่านการรับรองเมื่อผ่านการตรวจสอบความถูกต้องของภาพต้นฉบับ ภาพทำเครื่องหมาย และตำแหน่งรังนก
  • ชุดข้อมูลที่ 3 ใช้มาตรฐาน red_v1 สำหรับบันทึกแหล่งที่มาของ marker โดยไม่กระทบมาตรฐานเดิมของชุดข้อมูลก่อนหน้า และมีป้ายกำกับที่ตรวจสอบแล้ว 673 จุด

แนวทางการอัปเดตชุดข้อมูลถัดไป

เมื่อได้รับชุดข้อมูลใหม่ ให้เพิ่มข้อมูลของ Set 4 หรือชุดถัดไปใน window.datasetStatus.sets ระบบจะคำนวณยอดรวม จำนวนคู่ที่ยังขาด และความคืบหน้าสู่เป้าหมาย 300 คู่ภาพโดยอัตโนมัติ
