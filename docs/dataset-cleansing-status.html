สถานะการเตรียมข้อมูล

สรุปสถานะการทำความสะอาดและการใช้ชุดข้อมูล

ชุดข้อมูลที่ 1–3 ผ่านการตรวจสอบและรับรองครบ 240 คู่ภาพ และถูกนำเข้าสู่กระบวนการพัฒนาโมเดล Prototype แล้ว

สถานะโดยรวม

ชุดข้อมูลที่ 1–3 ผ่านการทำความสะอาด ตรวจสอบคุณภาพ และรับรองครบทั้ง 240 คู่ภาพแล้ว ข้อมูลทั้งหมดถูกนำเข้าสู่กระบวนการเตรียมข้อมูล แบ่งชุดข้อมูล พัฒนา และประเมินโมเดล Prototype โดยโครงการไม่ต้องรอให้ครบ 300 คู่ภาพอีกต่อไป

ตัวเลขสำคัญของข้อมูลที่ผ่านการรับรองและนำเข้าสู่ Prototype pipeline แล้ว

0% ขอบเขตข้อมูล Prototype

ความพร้อมของข้อมูลสำหรับ Prototype

ข้อมูลที่ผ่านการรับรองทั้ง 240 คู่ภาพถูกนำเข้าสู่กระบวนการเตรียมข้อมูล แบ่งชุดข้อมูล พัฒนา และประเมินโมเดล Prototype แล้ว สถานะข้อมูลของรอบนี้จึงถือว่าเสร็จสมบูรณ์ 100%

ผลการทำความสะอาดข้อมูลแยกตามชุด

ทุกชุดใช้โครงสร้างการรายงานเดียวกัน เพื่อให้เปรียบเทียบสถานะได้ชัดเจน

สถานะความพร้อมปัจจุบัน

ผลการดำเนินงาน
ขอบเขตข้อมูลสำหรับ Prototype รอบปัจจุบันเสร็จสมบูรณ์แล้ว ขั้นตอนถัดไปคือการตรวจผลโมเดลผ่าน Contact Sheet การส่งต่อให้ทีมโปรแกรมเมอร์ และการวางแผนพัฒนารุ่นถัดไป

หมายเหตุการตรวจสอบข้อมูล

  • ไฟล์ที่ไม่นำมาใช้ยังถูกเก็บไว้ พร้อมบันทึกเหตุผล เพื่อให้ตรวจสอบย้อนหลังได้
  • ข้อมูลจะนับเป็นคู่ภาพที่ผ่านการรับรองเมื่อผ่านการตรวจสอบความถูกต้องของภาพต้นฉบับ ภาพทำเครื่องหมาย และตำแหน่งรังนก
  • ชุดข้อมูลที่ 3 ใช้มาตรฐาน red_v1 สำหรับบันทึกแหล่งที่มาของ marker โดยไม่กระทบมาตรฐานเดิมของชุดข้อมูลก่อนหน้า และมีป้ายกำกับที่ตรวจสอบแล้ว 673 จุด

แนวทางเมื่อมีข้อมูลเพิ่มเติมในอนาคต

หากได้รับข้อมูลเพิ่มเติมในอนาคต สามารถเพิ่ม Set 4 หรือชุดถัดไปเข้าสู่ทะเบียนข้อมูลเพื่อขยายการวิจัยและปรับปรุงโมเดลได้ แต่ข้อมูลเพิ่มเติมไม่ใช่เงื่อนไขที่ต้องรอก่อนใช้งาน Prototype ปัจจุบัน ซึ่งใช้ขอบเขตข้อมูลที่ผ่านการรับรองครบ 240 คู่ภาพแล้ว
