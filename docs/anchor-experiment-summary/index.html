Interim management summary

ผลการทดลองปรับ Anchor และสถานะการประเมินโดยผู้เชี่ยวชาญ

สรุปความคืบหน้าการทดลองปรับ Faster R-CNN anchors สำหรับต้นแบบตรวจจุดสกปรกในภาพรังนก แยกชัดเจนระหว่างผลอัตโนมัติที่ทำเสร็จแล้วกับข้อสรุปสุดท้ายที่ยังต้องรอผู้เชี่ยวชาญตรวจยืนยัน

Current status เตรียมชุดข้อมูลสำหรับผู้เชี่ยวชาญแล้ว

ผลอัตโนมัติของชุด Anchor ใหม่ทำเสร็จแล้ว และอยู่ระหว่างรอผลตรวจยืนยันจากผู้เชี่ยวชาญก่อนสรุปแนวทางใช้งานจริง

Why this experiment was done

ได้รับมอบหมายให้ทดลองปรับ Anchor เพื่อประเมินผลกับจุดสกปรกขนาดเล็ก

ตามที่ได้รับมอบหมาย จึงทดลองปรับ Anchor ของ Faster R-CNN จากชุดเดิมไปเป็นชุดที่เน้นขนาดเล็กมากขึ้น เพื่อประเมินว่าสามารถตรวจจุดสกปรกขนาดเล็กได้ดีขึ้นหรือไม่ และช่วยลดจำนวนผลตรวจส่วนเกินที่ต้องให้ผู้เชี่ยวชาญพิจารณาภายหลัง

หน้านี้เป็นสรุปผลเบื้องต้นสำหรับติดตามความคืบหน้า ยังไม่ใช่ข้อสรุปสุดท้ายของโมเดล

What it suggests so far

แนวโน้มดีขึ้น แต่ยังต้องรอผลตรวจจากผู้เชี่ยวชาญ

แนวโน้มจากผลอัตโนมัติดีขึ้น

Recall และ automatic precision proxy เพิ่มขึ้น ขณะที่ unmatched predictions ลดลง

อาจลดภาระการตรวจ

จำนวนรายการที่ต้องพิจารณาลดลง 385 รายการ เมื่อเทียบกับ baseline เดิม

ยังไม่ควรสรุปผลก่อนการตรวจยืนยัน

ต้องรอผลตรวจของ Small Anchor ทั้ง 1,400 รายการ เพื่อเทียบ human-reviewed precision กับ baseline 7.17%

What happens next

ตรวจยืนยันและสรุปแนวทางปรับปรุงโมเดล

  • ส่งชุดข้อมูล Small Anchor ให้ผู้เชี่ยวชาญตรวจยืนยัน
  • รับผลตรวจจากผู้เชี่ยวชาญในรูปแบบ structured results กลับมา
  • เทียบ human-reviewed precision ของ Small Anchor กับ baseline 7.17%
  • วิเคราะห์สาเหตุของ false positives / false negatives ที่ยังเหลือ
  • ตัดสินว่าจะ adopt anchor ใหม่, ปรับ threshold, เพิ่ม hard negatives, หรือคง default anchor
