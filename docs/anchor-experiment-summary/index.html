Interim management summary

ผลการทดลองปรับ Anchor และสถานะการประเมินโดยผู้เชี่ยวชาญ

สรุปความคืบหน้าการทดลองปรับ Faster R-CNN anchors สำหรับต้นแบบตรวจจุดสกปรกในภาพรังนก แยกชัดเจนระหว่างผลอัตโนมัติที่ทำเสร็จแล้วกับข้อสรุปสุดท้ายที่ยังต้องรอผู้เชี่ยวชาญตรวจยืนยัน

Current status Phase 7 completed

เตรียม package สำหรับ expert review แล้ว และกำลังรอผลตรวจ Phase 8 เพื่อใช้ตัดสินขั้นสุดท้าย

Why this experiment was done

ทดลองตามคำสั่งหัวหน้า เพื่อวัดผล anchor ใหม่แบบควบคุม

หัวหน้าให้ทดลองปรับ anchor ของ Faster R-CNN จากชุดเดิมไปเป็นชุดที่เน้นขนาดเล็กมากขึ้น เพื่อดูว่าสามารถตรวจจุดสกปรกขนาดเล็กได้ดีขึ้นหรือไม่ พร้อมลดภาระจาก extra detections ที่ต้องตรวจภายหลัง

หน้านี้เป็นรายงานสถานะระหว่างทาง ไม่ใช่ข้อสรุปสุดท้ายของโมเดล

What it suggests so far

แนวโน้มดีขึ้น แต่ยังต้องรอผลตรวจจากผู้เชี่ยวชาญ

Automatic trend ดีขึ้น

Recall และ automatic precision proxy เพิ่มขึ้น ขณะที่ unmatched predictions ลดลง

อาจลดภาระการตรวจ

จำนวน prediction ที่ต้องพิจารณาลดลง 385 รายการ เมื่อเทียบกับ baseline เดิม

Decision ยังไม่ปิด

ต้องรอ expert review ของ Small Anchor ทั้ง 1,400 predictions เพื่อเทียบ human-reviewed precision กับ baseline 7.17%

What happens next

ขั้นตอนถัดไปเพื่อปิดข้อสรุป

  • ส่ง small-anchor review package ให้ผู้เชี่ยวชาญตรวจ
  • รับ structured expert review results กลับมา
  • เทียบ human-reviewed precision ของ Small Anchor กับ baseline 7.17%
  • วิเคราะห์สาเหตุของ false positives / false negatives ที่ยังเหลือ
  • ตัดสินว่าจะ adopt anchor ใหม่, ปรับ threshold, เพิ่ม hard negatives, หรือคง default anchor
