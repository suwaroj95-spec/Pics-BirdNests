01

โครงการนี้ทำอะไร และทำไมต้องทำ

โครงการนี้ศึกษาการใช้ computer vision ช่วยตรวจจับ candidate dirty spots หรือ “ตำแหน่งที่อาจเป็นจุดสกปรก” ในภาพรังนก เป้าหมายไม่ใช่การประกาศระบบตรวจคุณภาพอัตโนมัติสำเร็จรูป แต่คือการสร้างต้นแบบเชิงวิศวกรรมที่ตรวจสอบได้ทุกขั้นตอน

ระบบถูกจัดเป็น ENGINEERING / RESEARCH PROTOTYPE หมายถึงต้นแบบเพื่อพิสูจน์วิธีการ ทดลองข้อจำกัด และเตรียมข้อมูลสำหรับการประเมินโดยผู้เชี่ยวชาญ ยังไม่ใช่ production quality-control software, commercial automated inspection, หรือเครื่องมือแทนผู้เชี่ยวชาญมนุษย์

แก่นของงานวิจัยจาก marker reference เดิม สู่โมเดล Faster R-CNN ที่ถูกทดลองอย่างเป็นระบบ แล้วส่ง prediction ที่ยังตีความไม่ได้เข้าสู่ Expert Review

02

ชุดข้อมูล 240 คู่ภาพ และ Marker 7,115 จุด

ชุดข้อมูลตั้งต้นมี 240 คู่ภาพ Raw / Marker และมี 7,115 Marker reference points ที่ใช้เป็นหลักฐานเชิงบวกว่าในตำแหน่งนั้นมีสิ่งที่ควรถูกตรวจจับ

ประเด็นสำคัญคือ Marker presence = positive reference หรือการมี marker คือหลักฐานเชิงบวก แต่ Marker absence ไม่เท่ากับ confirmed negative การไม่มี marker จึงไม่ใช่หลักฐานว่าบริเวณนั้นไม่มีจุดสกปรกจริงเสมอไป

04

Faster R-CNN คืออะไร และตัวชี้วัดหมายถึงอะไร

Faster R-CNN MobileNetV3-Large-FPN เป็นโมเดลตรวจจับวัตถุที่หา candidate regions ก่อน แล้วประเมินว่าตำแหน่งนั้นเข้ากับ class ที่สนใจหรือไม่ งานนี้ใช้ 2 classes และรายงานผลแบบระมัดระวัง เพราะ Ground Truth มาจาก marker reference เดิม ไม่ใช่คำตัดสินสุดท้ายจากผู้เชี่ยวชาญ
