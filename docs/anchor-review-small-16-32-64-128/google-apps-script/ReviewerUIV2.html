Case

กำลังโหลดภาพสำหรับรายการนี้

คำตอบนี้ส่งแล้วและถูกล็อกไว้
คำแนะนำสำหรับการประเมิน
  • จุดสกปรกขนาดเล็กมากยังสามารถนับเป็นจุดที่ต้องประเมินได้
  • ขนาดเพียงอย่างเดียวไม่ใช่เหตุผลในการตัดออก
  • จุดขนาดใหญ่หรือรูปร่างไม่สม่ำเสมอให้ตัดสินจากภาพที่เห็น
  • จุดที่จางหรือคอนทราสต์ต่ำยังสามารถนับเป็นจุดที่ต้องประเมินได้
  • ใช้ ไม่แน่ชัด เมื่อไม่มั่นใจจริงๆ
  • ใช้ ไม่สามารถประเมินจากภาพได้ เมื่อคุณภาพภาพทำให้ตัดสินไม่ได้
  • จุดที่อยู่ติดกันภายในวงเครื่องหมายเดิมหนึ่งวงให้ถือว่าเป็นบริเวณเดียวกันเมื่อมีเครื่องหมายนั้นอยู่
  • สำหรับตำแหน่งตัวเลือกที่ไม่มีเครื่องหมายเดิม การไม่มีเครื่องหมายเดิมไม่ใช่หลักฐานว่าตำแหน่งนั้นเป็นลบ
  • ตำแหน่ง Annotation ไม่ตรงกับจุดสกปรก ใช้เฉพาะเมื่อเครื่องหมาย annotation เดิมเลื่อนจนไม่ครอบคลุมจุดสกปรกที่ตั้งใจไว้
